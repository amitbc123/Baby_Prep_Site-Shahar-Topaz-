# אור ירח

אתר הכנות פרטי לקראת ההגעה של הבת של שחר וטופז: רשימת קניות עם תקציב ועדיפויות, משימות (כולל תיק ליולדת), תאריכים ומשאלות, וספירה לאחור עד הירח המלא.

כרגע ללא שרת — כל המידע נשמר במכשיר שבו נפתח האתר (localStorage). ניתן לגבות ולשתף נתונים בין מכשירים דרך "ייצוא/ייבוא" בהגדרות.

## פיתוח מקומי

```bash
npm install
npm run dev
```

## פריסה ל-GitHub Pages

הפריסה אוטומטית דרך GitHub Actions (`.github/workflows/deploy.yml`) בכל push ל-`main`.
בפעם הראשונה: ב-Settings → Pages של הריפו, יש לבחור Source = **GitHub Actions**.

בסיס הנתיב (`base`) ב-`vite.config.ts` מוגדר לפי שם הריפו הנוכחי. אם שם הריפו משתנה, יש לעדכן שם.
